### 2.3 Documentation of Minor Finding (Floating-Point Precision)
The independent calculation from CSV yielded a difference of $\approx 2.14 \times 10^{-6}$ on the fuzzy scores compared to `summary.json`. 
- **Cause**: In `experiment2_formal.py`, the summary statistics were evaluated directly on the in-memory 64-bit numpy float arrays. When exported to CSV via pandas `to_csv()`, floating-point numbers were formatted as text, truncating extreme sub-micro decimal places. Baseline scores are exact integers or simple decimal fractions and thus exhibited zero truncation error.
- **Materiality**: The difference is negligible ($0.00028\%$), rounded to four decimal places ($0.7630$ and $0.4884$) the numbers are identical, and no test conclusion is altered.

## 3. Task 2: Bootstrap Statistical Inference Validation

The paired, null-centered claim-level cluster bootstrap procedure was independently implemented following the exact approved protocol:
- **Resampling level**: Claims ($M = 500$, preserving all 3 retrieved evidence pieces per claim).
- **Random Number Generator**: `numpy.random.Generator(PCG64(42))`.
- **Replicate count**: $B = 1,000$.
- **Replicate validity**: 1,000 valid resamples, 0 degenerate resamples (no sample had all gold or all distractors).
- **Centering formula**: $\tilde{\Delta}^* = \Delta^* - \hat{\Delta}$.
- **Two-sided empirical $p$-value**: $p = \frac{1 + \sum_{b=1}^B \mathbb{I}(|\tilde{\Delta}_b^*| \ge |\hat{\Delta}|)}{B + 1}$.

### 3.2 Multiplicity Adjustment Step-Down Verification
1. Ordered $p$-values: $p_{(1)} = p_{\text{AP}} = 0.000999$, $p_{(2)} = p_{\text{AUROC}} = 0.023976$.
2. Step 1 ($H_2$: AP): Compare $p_{(1)}$ against $\alpha / 2 = 0.025$. Since $0.000999 \le 0.025$, reject $H_{0,2}$ ($p_{\text{Holm}} = 0.000999 \times 2 = 0.001998$).
3. Step 2 ($H_1$: AUROC): Compare $p_{(2)}$ against $\alpha / 1 = 0.050$. Since $0.023976 \le 0.050$, reject $H_{0,1}$ ($p_{\text{Holm}} = \max(0.001998, 0.023976 \times 1) = 0.023976$).
- **Conclusion**: Both co-primary hypotheses are confirmed statistically significant under FWER $\alpha = 0.05$.
